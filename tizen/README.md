## מה האפליקציה זוכרת, ואיפה

הזיכרון של המשתמש הוא מסמך JSON קטן אחד, בשלושה חלקים:

| מה | טייזן (`localStorage`) | אנדרואיד (`SharedPreferences`) |
|---|---|---|
| היסטוריה — מה נוגן, מתי, ואיפה עצרת | `talohimHistoryV1` | `recent` |
| מועדפים | `talohimFavoritesV1` | `favorites` |
| סימוני "כבר צפיתי" | `talohimWatchedV1` | `watched` |

הכל מקומי למכשיר. "נצפה" **נגזר** משני אלה — סימון ביד או ניגון מעל 95%
— ולא נשמר בנפרד, כדי שהשניים לא יוכלו לסתור זה את זה
(`Core.watchedSet` / `HomeRows.watchedSet`).

הצורה הזו נבחרה כדי שאפשר יהיה להוסיף סנכרון בין מכשירים בלי לגעת
במסכים: שכבת סנכרון צריכה רק לדחוף ולמשוך את שלושת המפתחות האלה.

## עדכון גרסה בלי להתחבר מחדש

**אנדרואיד.** מערכת ההפעלה מתקינה גרסה חדשה מעל ישנה רק כששתיהן חתומות
באותו מפתח. בנייה של דיבאג נחתמת במפתח חד־פעמי ש-Gradle מייצר במקום,
ומכונת ה-CI היא מכונה חדשה בכל פעם — ולכן כל בנייה יצאה חתומה במפתח אחר,
כל התקנה דרשה הסרה קודם, וההסרה לקחה איתה את פרטי ההתחברות ואת ההיסטוריה.

הבנייה תומכת עכשיו במפתח קבוע. כדי להפעיל אותו, פעם אחת:

```bash
keytool -genkeypair -v -keystore telohim.jks -alias telohim \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 telohim.jks    # macOS: base64 -i telohim.jks
```

ואז ב-Settings → Secrets and variables → Actions:

| סוד | תוכן |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | הפלט של הפקודה השנייה |
| `ANDROID_KEYSTORE_PASSWORD` | הסיסמה שבחרת |
| `ANDROID_KEY_ALIAS` | `telohim` |
| `ANDROID_KEY_PASSWORD` | הסיסמה שבחרת (אם ביקשת אחרת למפתח) |

שמור את `telohim.jks` אצלך; אין דרך לשחזר אותו, ובלעדיו לא תוכל יותר
לעדכן מעל ההתקנה הקיימת. אל תכניס אותו למאגר — הוא ציבורי, והקובץ
מסונן ב-.gitignore.

**הפעם האחת האחרונה**: ההתקנה הראשונה אחרי המעבר עדיין דורשת הסרה, כי
היא עוברת ממפתח ישן לחדש. מכאן והלאה כל בנייה מתקינה מעל.

**טייזן.** החבילה נחתמת בתעודה שלך. כל עוד אתה חותם באותה תעודה ומזהה
האפליקציה נשאר `MlayferTV1`, ההתקנה עוברת מעל והזיכרון נשמר. תעודה אחרת,
או הסרה של האפליקציה, מוחקות אותו.
